Claude Draws a Birb — Cutout Bird

Subtractive technique: layers of color carved by SVG masks
How it works: Each color region is a full-canvas rectangle. SVG <mask> elements carve the shape — white reveals, black hides. Layers stack bottom-up: background → orange body → dark wing+head → blue-gray strip → yellow belly → details. No shape is placed additively on top; every boundary is defined by what the mask removes.
